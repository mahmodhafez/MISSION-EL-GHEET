## Built and verified (14 Nov 2026)

Vite 8 + React 19 + TypeScript 7 + Tailwind 4 app in `frontend/` implementing the voice-first labs (`work/ux-phase-4/`) as one flow:
Start (logo, audio unlock) → check / explore → practice mic (real browser recogniser) → four seasons (crops from the catalogue,
season-limited dates, no past dates, berseem sowing may be past) → what must stay → what may change → readback + one confirm →
Promise Test result (conflict pictures, Why? steps) → alternatives (feasible ≤2, review dates, blocked/incomplete search) →
before/after + why review → check again → summary + save; past weather and 7-day outlook side screens. Arabic RTL / English LTR.

- **Data:** `PlannerClient` interface with a labelled **dev adapter**. It returns the **real meg_core planner output** for UH-001
  (`src/services/dev/uh001.json`, regenerated by `scripts/export_dev_fixture.py`) only when the entered plan matches the fixture
  exactly; any other plan → "checking not connected". Saving, replay → `unavailable`; forecast → `not_applicable` for UH-001.
  Screens read planner codes/params (`sowing_before_protected_cut`, `preparation_shortfall`, unknown checks, exclusions); no
  UH-001 text is hard-coded in the result screens.
- **Speech:** Web Speech recognition (ar-EG / en-US) push-to-talk; device voice for output, labelled; a dev keyword extractor
  returns the Gemini schema shape until `/speech/interpret` exists.
- **Verified:** `pnpm typecheck`, `pnpm build` and `pnpm test` (12 unit tests) pass. A headless-Chromium click-through of the full
  UH-001 journey (26 steps, at 390×760 and 1280×820, English plus Arabic summary) reached the real result (rejected; review dates
  28 May and 1 June; season-4 maize not checked, search incomplete) with no script errors, horizontal overflow or scrolling.
- **Not verified:** real phones, real Arabic speech recognition or device voices, screen readers, farmers, the backend.
- **Supply chain (14 Nov):** pnpm 10.34.9 pinned by hash via corepack; `.npmrc` `minimum-release-age` 14 days; lockfile
  re-resolved under that rule (173 packages, all with integrity hashes, none with install scripts). `scripts/check_dependency_age.py`
  passes. Typecheck, 12 tests and build pass on the new lockfile. Rules: [dependencies.md](../rules/dependencies.md).
- **HTTP mode (14 Nov):** `src/services/http/httpAdapter.ts` sends answers to `POST /scenarios/from-answers`, runs the Promise Test
  with `?locale`, saves review cards, re-renders on language switch, and plays the backend's `speech` wording. Verified with a
  headless click-through of the full UH-001 journey against the running backend (390×760 and 1280×820): real result, backend
  wording for “not checked”, card saved; no errors, overflow or scrolling. Without a Gemini key the dev keyword stand-in is used.
- **Final integration (14 Nov):** crops come from the reviewed KB catalogue (8 offerable; names for rice, faba bean, sugar beet,
  Egyptian cotton; purposes sugar/fibre; unknown picture until Moaaz draws them), 4 per screen with "More crops", one
  "needs review" note on the crop question; "Another crop" opens its own picture screen on "what may change"; Past weather
  shows real Season Replay cards (date, status, average Tmax, ET0 total) and one plain summary. Full journey verified
  against the running backend, both widths, no scrolling.
- **Crops UI (14 Nov, later):** coloured drawings for rice, faba bean (pods), sugar beet and Egyptian cotton. With more than 4
  crops every crop is visible at once, with no paging: row tiles (picture | name | 44px listen) in 2 columns on phone and 4 on
  desktop; one "needs review" note beside the question; the "Another crop" picker uses the same layout. Verified: full journey
  at 390×760 and 1280×820 with no scrolling. Drawings are placeholders for Moaaz's pictures and a farmer recognition test.
- **UI review (14 Nov, later):** four parallel visual reviews of all 22 screens (360/650/1280, AR/EN) plus an automated audit
  at 12 widths (360–1440 px; clipping, overlap, overflow, mid-word breaks, buttons touching tile borders, scrolling). Fixed:
  RTL Back/arrow mirroring, fixed-size status badges, constant-height season strip, dock captions on phone, one gutter,
  actions at the bottom with centred content, full-width button rows, unknown (not red) style for "not checked", green
  permission chips, success style for Saved, Arabic decimal separator and °C in replay, current-language Start button.
  Audit clean at all 12 widths in both languages. Deliberately not changed: Arabic year order (earlier year on the right, by
  decision) and listen buttons stay 44 px (minimum target).
- **Known gaps:** harvest dates for maize, wheat and sorghum are not asked (the fixture supplies illustrative ones); season month
  windows are placeholders (voice-first.md open question 6); crop pictures are drawings.
