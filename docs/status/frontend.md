## Built and verified (14 Nov 2026)

Vite 8 + React 19 + TypeScript 7 + Tailwind 4 app in `frontend/` implementing the voice-first labs (`work/ux-phase-4/`) as one flow:
Start (logo, audio unlock) → check / explore → practice mic (real browser recogniser) → four seasons (crops from the catalogue,
season-limited dates, no past dates, berseem sowing may be past) → what must stay → what may change → readback + one confirm →
Promise Test result (conflict pictures, Why? steps) → alternatives (feasible ≤2, review dates, blocked/incomplete search) →
before/after + why review → check again → summary + save; past weather and 7-day outlook side screens. Arabic RTL / English LTR.

- **Data:** `PlannerClient` interface with a labelled **dev adapter**. It returns the **real meg_core planner output** for UH-001
  (`src/services/dev/uh001.json`, regenerated by `scripts/export_dev_fixture.py`) only when the entered plan matches the fixture
  exactly; any other plan → "checking not connected". Saving, replay → `unavailable`; forecast → `not_applicable` for UH-001.
  Screens read planner codes/params (`sowing_before_protected_cut`, `preparation_shortfall`, unknown checks, exclusions); no
  UH-001 text is hard-coded in the result screens.
- **Speech:** Web Speech recognition (ar-EG / en-US) push-to-talk; device voice for output, labelled; a dev keyword extractor
  returns the Gemini schema shape until `/speech/interpret` exists.
- **Verified:** `pnpm typecheck`, `pnpm build` and `pnpm test` (12 unit tests) pass. A headless-Chromium click-through of the full
  UH-001 journey (26 steps, at 390×760 and 1280×820, English plus Arabic summary) reached the real result (rejected; review dates
  28 May and 1 June; season-4 maize not checked, search incomplete) with no script errors, horizontal overflow or scrolling.
- **Not verified:** real phones, real Arabic speech recognition or device voices, screen readers, farmers, the backend.
- **Known gaps:** harvest dates for maize, wheat and sorghum are not asked (the fixture supplies illustrative ones); season month
  windows are placeholders (voice-first.md open question 6); crop pictures are drawings.
